# Hi, I'm Pablo Sala 👋

Mathematician from Barcelona who likes building things that think. I'm heading towards **AI engineering**: agents that do real work, sit on solid data, and ship to production on the cloud. I learn by building. Every new topic becomes a small project, broken, fixed and written up. Right now that means tool-use agents, RAG with real evals, voice, and observability. Away from the keyboard, I keep an eye on financial markets and crypto, and I like to build tools for them.

---

## 🚧 Building now

### 📈 Market Desk
An AI research desk for public companies, over chat and voice. It answers with citations, grounded in verified facts and SEC filings. A hand-written tool-use agent on the Claude API, hybrid RAG with measured evals, an MCP server, a React + TypeScript dashboard and an AWS deployment with Terraform, built in public sprint by sprint.

[Repository](https://github.com/schecop/market-desk) · [Roadmap](https://github.com/schecop/market-desk#roadmap) · [Learning journal](https://schecop.github.io/market-desk/)
